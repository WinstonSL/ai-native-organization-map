7 问分析框架

看到任何新的“Agent OS / AI Workspace”产品时，用这 7 问拆解

01Work它到底在做什么工作？工作有没有被重新设计？
02Context它需要知道什么？上下文从哪里来，如何持续更新？
03Agent谁来做？单 Agent、Skill 还是长期角色？
04Coordination多个 Agent 如何分工、交接、冲突与汇总？
05Workspace人和 AI 在哪里共享文件、任务、状态与历史？
06Governance谁拥有它？能访问什么？高风险动作谁批准？
07Organization最终人的岗位、管理层级、流程和决策权如何改变？
判断技巧：不要先问“它有没有 Agent”，而要问“它的一等对象是什么？” Meco 的一等对象更接近 AI Coworker；Asana 是 Work / Task；Taskade Genesis 是 App / System；Multica 是 Human-Agent Work Management。
